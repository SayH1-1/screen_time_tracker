# ⏱️ Screen Time Tracker

A lightweight desktop application built in Python to track your daily computer screen time. Runs quietly in the system tray and saves data automatically.

---

### 🇺🇦 Про програму
Легкий десктопний додаток на Python для відстеження часу, проведеного за комп'ютером. Працює у фоновому режимі (в треї) та автоматично зберігає результати.

* 🚀 **Основні можливості:** точний підрахунок часу, мінімалістичний інтерфейс, робота в системному треї, збереження у локальний файл.
* 📥 **Як завантажити:** Перейдіть у розділ [Releases](../../releases/latest) та завантажте останню версію `v1.0`.

---

### 🇬🇧 About
A lightweight Python desktop application for tracking computer screen time. It runs quietly in the system tray and saves your progress automatically.

* 🚀 **Key Features:** precise time tracking, minimalist UI, system tray integration, local file auto-saving.
