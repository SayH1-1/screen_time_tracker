# ⏱️ Screen Time Tracker
### 🇺🇦 Про програму

* 🚀 **Функції:**
  * Підрахунок часу за поточний день у реальному часі.
  * Календар для перегляду статистики за будь-яку дату.
  * Автоматичне збереження даних по кожній даті в локальний файл `screen_time_data.json`.
  * Згортання в системний трей і швидке відкриття вікна одним кліком по іконці.
  * Перемикання між темною та світлою темами.

* 📥 **Як завантажити та запустити:**
  1. Перейдіть у розділ [Releases](../../releases) та завантажте останню версію (`v1.2`).
  2. Розпакуйте або збережіть `.exe` файл у зручну папку на комп'ютері.
  3. Запустіть програму подвійним кліком — облік часу та збереження даних почнуться автоматично.

---
### 🇬🇧 About

* 🚀 **Features:**
  * Real-time screen time tracking for today.
  * Calendar view to check time for any date.
  * Automatic saving of every date and time to a local `screen_time_data.json` file.
  * Minimize to the system tray and reopen the window with a single click on the tray icon.
  * Dark and light theme switch.

* 📥 **How to Download and Run:**
  1. Go to the [Releases](../../releases) section and download the latest version (`v1.2`).
  2. Save the `.exe` file to a folder on your computer.
  3. Double-click to run — tracking and saving work automatically.
