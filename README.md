# ⏱️ Screen Time Tracker

A lightweight desktop application built in Python with CustomTkinter to track your daily computer screen time. Features a clean minimalist UI, dark/light theme switching, and automatic local data saving.

---

### 🇺🇦 Про програму

Легкий десктопний додаток на Python (CustomTkinter) для відстеження часу, проведеного за комп'ютером. Працює у фоновому режимі та автоматично зберігає результати.

* 🚀 **Основні можливості:** точний підрахунок часу за сьогодні, перемикання між темною та світлою темами, мінімалістичний інтерфейс, автоматичне збереження у локальний файл.
* 📥 **Як завантажити:** Перейдіть у розділ [Releases](../../releases) та завантажте останню версію `v1.1`.

---

### 🇬🇧 About

A lightweight Python desktop application built with CustomTkinter for tracking computer screen time. It runs in the background and saves your progress automatically.

* 🚀 **Key Features:** precise daily time tracking, dark/light theme toggle, minimalist UI, local file auto-saving.
